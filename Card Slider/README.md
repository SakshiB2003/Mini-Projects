# 🃏 Demon Slayer Card Slider

A visually stunning **Demon Slayer (Kimetsu no Yaiba) card slider** built with **Swiper.js**.  
Slide through your favorite characters with smooth transitions, badges, and responsive layout!

## 🎨 Features

- 🎴 Swipeable card slider using **Swiper.js**
- 🖼️ Display multiple characters with **custom images**
- 🏷️ Color-coded badges for each character
- ⚡ Smooth hover effects and button interactions
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🎯 Easy to customize for other anime or character collections

---

## 🛠️ Built With

- ⚙️ **HTML5 & CSS3**
- 🎨 **Custom CSS for styling & badges**
- 🚂 **Swiper.js** for interactive slider
- 🖱️ **JavaScript** for slider initialization
- 🌐 **Google Fonts – Material Symbols** for navigation arrows
